# job4j_accidents

Проект "Автонарушители" — веб-приложение для регистрации автомобильных нарушений.

Пользователь может создать заявку с описанием нарушения, адресом, номером автомобиля и фотографией.

У заявки есть статусы:

- принята;
- отклонена;
- завершена.

## Роли

- пользователь;
- автоинспектор.

## Технологии

- Java
- Spring
- Maven
- PostgreSQL
